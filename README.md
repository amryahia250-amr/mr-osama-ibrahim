# Mr.Osama Ibrahim — منصة تعليمية تجريبية

موقع تعليمي عربي باتجاه RTL، مبني باستخدام HTML وCSS وJavaScript فقط. مناسب للمبتدئ ويمكن نشره مجانًا على GitHub Pages.

## تشغيل الموقع على جهازك
1. فك ضغط ملف المشروع.
2. افتح مجلد `Mr-Osama-Ibrahim`.
3. افتح `index.html` في متصفح حديث.
4. جرّب الدروس والاختبارات والملف الشخصي ولوحة المدرّس التجريبية.

لا يحتاج الموقع إلى تثبيت مكتبات أو تشغيل أوامر.

## الملفات
- `index.html`: بنية الصفحات ومكونات الموقع.
- `style.css`: الألوان والتنسيق والتصميم المتجاوب للموبايل والكمبيوتر.
- `script.js`: الدروس والاختبارات والتفاعلات والحفظ المحلي.
- `README.md`: هذا الدليل.

## رفع المشروع إلى GitHub
1. أنشئ حسابًا مجانيًا على https://github.com إن لم يكن لديك حساب.
2. اضغط علامة `+` ثم `New repository`.
3. سمِّ المستودع مثلًا `mr-osama-ibrahim` واجعله `Public` إذا أردت استخدام GitHub Pages مجانًا.
4. أنشئ المستودع.
5. اختر `Add file` ثم `Upload files`.
6. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js`، ويمكنك رفع `README.md` أيضًا.
7. اضغط `Commit changes`.
8. افتح `Settings` ثم `Pages`.
9. تحت `Build and deployment` اختر `Deploy from a branch`.
10. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
11. انتظر قليلًا ثم افتح الرابط الذي يظهر في صفحة Pages. غالبًا يكون بالشكل:
   `https://YOUR-USERNAME.github.io/mr-osama-ibrahim/`

استبدل `YOUR-USERNAME` باسم حسابك الفعلي. قد يستغرق النشر عدة دقائق.

## ماذا يعمل الآن؟
- عرض ثلاثة دروس عربية تجريبية.
- اختبار اختيار من متعدد مع تصحيح ونتيجة.
- ملف طالب باسم مستعار.
- حفظ الدروس المكتملة والنتائج والمحتوى المضاف باستخدام `localStorage` في المتصفح الحالي.
- مساعد تعليمي تجريبي يجيب عن عدد محدود من الموضوعات.
- لوحة تجريبية لإضافة الدروس والأسئلة وحذف المحتوى المضاف.

## حدود النسخة الحالية — مهم
هذه **نسخة أولية تعليمية وليست نظامًا إنتاجيًا آمنًا**:
- لا توجد حسابات حقيقية أو كلمات مرور أو قاعدة بيانات مشتركة. البيانات محفوظة في متصفح الجهاز نفسه، ويمكن أن تختفي عند مسح بيانات المتصفح.
- لوحة المدرّس مفتوحة لأي زائر؛ لا تضع فيها معلومات خاصة ولا تعتبرها لوحة إدارة محمية.
- المساعد التعليمي ليس ذكاءً اصطناعيًا متصلًا بخدمة خارجية؛ يستخدم ردودًا محلية محدودة.
- محتوى لوحة المدرّس لا ينتقل تلقائيًا إلى أجهزة الزوار الآخرين.
- GitHub Pages يستضيف ملفات ثابتة، ولا يشغّل خادمًا خلفيًا أو يخفي مفاتيح API.

## خطوات التطوير التالية
1. ربط تسجيل الدخول وقاعدة البيانات بخدمة خلفية مثل Supabase أو Firebase، مع مراجعة حدود الخطة المجانية وسياسات الأمان الحالية.
2. حماية صلاحيات المدرّس من جهة الخادم، لا بمجرد إخفاء زر في الواجهة.
3. ربط المساعد بنموذج ذكاء اصطناعي عبر خادم وسيط يحتفظ بالمفتاح السري. لا تضع مفتاح API داخل `script.js` أو أي ملف منشور للعامة.
4. إضافة مراجعة للمحتوى ووسيلة للإبلاغ عن الأخطاء، خصوصًا لأن المستخدمين طلاب مدارس.

يمكنك تعديل المشروع وتطويره لاحتياجاتك. راجع تراخيص أي خدمات أو مكتبات خارجية تضيفها لاحقًا.
