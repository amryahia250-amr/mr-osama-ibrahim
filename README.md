# Mr.Osama Ibrahim — واجهة مطوّرة

نسخة واجهة عربية RTL مناسبة للموبايل، متخصصة في الفيزياء والعلوم المتكاملة، وتتضمن:
- واجهة ترحيب وتسجيل دخول/إنشاء حساب.
- حقول التسجيل المطلوبة: الاسم الرباعي، رقم الطالب، رقم ولي الأمر، المحافظة، المدينة، الرقم القومي، الصف الدراسي، كلمة المرور وتأكيدها.
- لوحة طالب تجريبية وشريط تنقل سفلي.
- واجهة شكلية للوحة المدرّس.

## مهم قبل النشر
هذه **واجهة أمامية تجريبية فقط** وليست نظام حسابات فعليًا. النماذج لا تحفظ بيانات التسجيل ولا كلمات المرور ولا الرقم القومي، وتعرض تنبيهًا بأن المصادقة تحتاج إعدادًا آمنًا. لا تضف كلمة مرور المدرّس أو أي مفاتيح سرية داخل ملفات HTML/JS المنشورة.

GitHub Pages يستضيف ملفات ثابتة ولا يستطيع وحده تنفيذ التحقق الآمن من كلمات المرور أو الموافقة الإدارية. لتفعيل المطلوب بالكامل يجب ربط Backend وقاعدة بيانات مع:
1. تخزين كلمات المرور باستخدام hashing آمن على الخادم، وليس كنص صريح.
2. التحقق من الهاتف وكلمة المرور على الخادم وإنشاء جلسة آمنة.
3. حالة حساب `pending/approved/rejected` لا يستطيع الطالب تغييرها.
4. صلاحيات إدارية تتحقق على الخادم، وليس بمجرد إخفاء الأزرار.
5. قواعد وصول تجعل الطالب يقرأ محتوى صفه فقط.
6. تشفير وحماية الرقم القومي ورقم ولي الأمر، وتحديد مدة الاحتفاظ بها وعدم جمعها إلا عند الضرورة.

## النشر على GitHub Pages من الموبايل
1. افتح مستودعك `mr-osama-ibrahim`.
2. ارفع `index.html` و`style.css` و`script.js` و`README.md` من هذا المجلد.
3. وافق على استبدال الملفات القديمة ثم اضغط **Commit changes**.
4. افتح رابط GitHub Pages وانتظر تحديث الصفحة. إذا لم يظهر التحديث فورًا، حدّث الصفحة أو امسح ذاكرة التخزين المؤقت.

## ملاحظة
لا يتم إنشاء حساب مدرس تلقائيًا في هذه النسخة. بيانات دخول المدرس يجب إعدادها في النظام الخلفي الآمن بعد اختيار خدمة الاستضافة الخلفية.
